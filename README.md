# Protein neural networks under shared translational resources

Simulation notebooks accompanying the manuscript:

**Sequestration-based Protein Neural Networks Tolerate the Effects of Shared Translational Resources**

## Notebooks

- `activation_functions_and_ribosome_allocation.ipynb`:
  Activation functions, ribosome allocation, and resource-competition onset.

- `single_perceptron_decision_boundaries.ipynb`:
  Single-perceptron decision boundaries and binding-affinity uncertainty.

- `multilayer_protein_neural_networks.ipynb`:
  Multilayer network simulations and uncertainty regions for Figures 5–6.

## Running the simulations

Open a notebook in Jupyter or Google Colab.
Run its setup and model-definition cells before running the simulations.
